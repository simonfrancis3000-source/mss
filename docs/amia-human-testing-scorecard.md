# AMIA human conversation scorecard

Plan: 15–20 people, three sessions of roughly 15 minutes each. Use a test account and avoid credentials, addresses or other sensitive details. Obtain agreement before recording audio. A person can stop at any time.

Session 1: Teach a household preference, explain why, add an exception, and ask AMIA to explain what it understood.

Session 2: Return later, resume, correct a preference, briefly change the subject, and create a reminder. Check the reminder exists.

Session 3: Speak naturally, use a short or ambiguous answer, interrupt a reply, pause and return. Try a different topic and a reminder cancellation.

After each session, score each item from 1 (poor) to 5 (excellent):

| Item | Score | Example or turn number |
| --- | --- | --- |
| Understood what I meant | | |
| Follow-ups were relevant and useful | | |
| Remembered my preferences and corrections | | |
| Conversation felt natural | | |
| Pace and pauses felt comfortable | | |
| Interruptions worked | | |
| I understood what was saved or completed | | |
| I would choose to continue another day | | |

Also record device, language, session length, start/end time and app build. Mark any invented action, incorrect permission, repeated settled question, forgotten correction, audio clipping or interruption failure separately. A high average must not hide those failures.

Ask: What was the most awkward moment? What did AMIA ask that helped you think of something useful? What would make you stop using it? Were any questions too personal or repetitive?

Keep participant feedback separate from automated results. Human sessions have not been completed by building this scorecard. Do not describe the application as a validated physical-robot controller.
